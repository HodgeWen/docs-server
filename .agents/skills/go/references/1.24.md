# Go 1.24

本文件只适用于 **`go` 行 1.24.x**。不要用更新档才有的 API：`new(expr)`、类型参数自引用约束、`go fix` modernizer 套件、Green Tea GC 当默认、`testing/synctest.Test` 当稳定默认、`encoding/json/v2`、`sync.WaitGroup.Go`、`errors.AsType`、`crypto/hpke`、`bytes.Buffer.Peek`、`testing/cryptotest`、`http.CrossOriginProtection`、容器感知 `GOMAXPROCS` 默认、`simd/archsimd` / `runtime/secret` / goroutine leak profile、泛型方法、struct 字面量选择器 key、`encoding/json/v2` 转正（1.27）、std `uuid`、`crypto/mldsa`。

1.24.z 是安全与缺陷补丁，不改推荐写法。

## 语言：泛型 type alias

需要别名、不要新定义类型时用。必须带类型实参；别名不能挂方法。

```go
type Set[T comparable] = map[T]struct{}
s := Set[string]{"a": {}}
```

不要 `type Set[T comparable] map[T]struct{}` 然后再和 `map[T]struct{}` 混用。不要设 `GOEXPERIMENT=noaliastypeparams`。

## 工具：`go.mod` 的 `tool`

删掉 `tools.go` 空 import。用 `go get -tool <包路径>`，用 `go tool <名字>` 跑。

```
tool golang.org/x/tools/cmd/stringer
```

`go get tool` 升级全部；`go install tool` 装到 `GOBIN`。`go` 行 ≥ 1.24 时，`fmt.Printf(s)` 且 `s` 非常量、无其它参数会被 vet；改 `fmt.Print(s)`。`//go:build go1.23.1` 非法，写 `go1.23`。

## 运行时

内置 `map` 默认 Swiss Table。不要为「旧 map」写兼容，不要默认开 `GOEXPERIMENT=noswissmap`。

## `encoding/json`：`omitzero`

零值要省略用 `omitzero`。零值 `time.Time` **不要**再靠 `omitempty`（它不是 empty）。类型有 `IsZero() bool` 时走该方法。

```go
type Event struct {
	Name string    `json:"name"`
	At   time.Time `json:"at,omitzero"`
}
```

## `os.Root`

不信任的相对路径用 `os.OpenRoot`，不要 `os.Open(filepath.Join(dir, name))`。1.24 有：`Open` / `OpenFile` / `Create` / `Mkdir` / `Remove` / `Stat` / `Lstat` / `OpenRoot` / `FS` / `Close`。**没有** `WriteFile` / `ReadFile` / `MkdirAll`。

```go
root, err := os.OpenRoot(dir)
if err != nil { return err }
defer root.Close()
f, err := root.Open(name)
```

## 测试与清理

基准用 `for b.Loop() { ... }`，不要 `for range b.N`。setup/cleanup 放 Loop 外（每个 `-count` 只跑一次）。测试里用 `t.Context()`，不要自己 `context.WithCancel` 再在 `t.Cleanup` 里取消。

新代码用 `runtime.AddCleanup`，不要 `SetFinalizer`。`cleanup`/`arg` 不要引用 `ptr`；长任务在 cleanup 里再起 goroutine。1.24 的 cleanup 由**单 goroutine 串行**执行。

## iterator：`bytes` / `strings`

只要遍历、不要切片，用 `Lines` / `SplitSeq` / `SplitAfterSeq` / `FieldsSeq` / `FieldsFuncSeq`。

```go
for line := range strings.Lines(s) {
	line = strings.TrimRight(line, "\n")
}
```

不要先 `strings.Split` 再 `range`。`Lines` 是单次 iterator，行含换行符。

## crypto 进标准库

用 `crypto/mlkem`、`crypto/hkdf`、`crypto/pbkdf2`、`crypto/sha3`，不要再拉 `golang.org/x/crypto` 的同名实现。签名与 x/crypto **不同**：`hkdf.Key` 的 `info` 是 `string`；`pbkdf2.Key` 的 password 是 `string`（1.24 的包注释示例误写成 `[]byte`，以函数签名为准）。

```go
dk, err := pbkdf2.Key(sha256.New, password, salt, 4096, 32)
key, err := hkdf.Key(sha256.New, secret, salt, "context", 32)
sum := sha3.Sum256(data)
```

默认 ML-KEM 用 768：`mlkem.GenerateKey768`。`crypto/rand.Read` 失败会崩溃，返回的 `error` 保证为 `nil`（被覆盖的 `Reader` 除外）。

## `testing/synctest`

实验 API，必须 `GOEXPERIMENT=synctest`，且 1.25 已换签名。**不要当默认 API**，不要在业务测试里开这个 experiment。
