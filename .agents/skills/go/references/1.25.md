# Go 1.25

本文件适用于 **`go` 行 1.25.x**。1.24 已稳定的写法继续用（`omitzero`、`os.Root`、`b.Loop()`、`AddCleanup`、`tool`、泛型 alias、std crypto）。不要用 1.26 才有的：`new(expr)`、类型参数自引用约束、改写后的 `go fix` modernizer 套件、Green Tea GC **默认**、`errors.AsType`、`crypto/hpke`、`bytes.Buffer.Peek`、`testing/cryptotest.SetGlobalRandom`、`simd/archsimd`、`runtime/secret`、goroutine leak profile。也不要用 1.27 才有的：泛型方法、struct 字面量选择器 key、`encoding/json/v2` 转正、std `uuid`、`crypto/mldsa`、`CutLast`、`synctest.Sleep`、`httptest.NewTestServer`、`url.Clone`。

无新语法。1.25.z 是安全与缺陷补丁（含 `testing/synctest` 实现修复），不改公开 API。

## 先判 `err`

1.21–1.24 编译器曾错误推迟 nil 检查，下面这种「先用后判」会跑过；**1.25 会 panic**，必须立刻判错：

```go
f, err := os.Open(path)
if err != nil {
	return err
}
name := f.Name()
```

不要 `f, err := os.Open(path); name := f.Name(); if err != nil { ... }`。

## 运行时

Linux 上默认 `GOMAXPROCS` 取 **cgroup CPU limit** 与逻辑 CPU 的较小值（K8s 的 CPU limit，不是 request），并会随 limit 变化更新。不要再手拧成 `runtime.NumCPU()`，除非有意覆盖。有意覆盖用环境变量或 `runtime.GOMAXPROCS`；要恢复默认用 `runtime.SetDefaultGOMAXPROCS`。关容器感知：`GODEBUG=containermaxprocs=0`。

Green Tea GC 仍是实验：`GOEXPERIMENT=greenteagc`。不要假设已默认开启。

`AddCleanup` 改为并行执行。不要假设 cleanup 串行；仍会阻塞的工作要另起 goroutine。

## `testing/synctest` 转正

并发测试用 bubble + 假时钟，不要在真实时钟上 `Sleep` 重试。bubble 里的 `time.Sleep` 走假时钟。API 是 `Test`，不是 1.24 实验里的 `Run`（`Run` 仅在 `GOEXPERIMENT=synctest` 下残留，1.26 删除）。bubble 内不要 `t.Run` / `t.Parallel` / `t.Deadline`。

```go
func TestDeadline(t *testing.T) {
	synctest.Test(t, func(t *testing.T) {
		ctx, cancel := context.WithTimeout(t.Context(), time.Second)
		defer cancel()
		time.Sleep(time.Second)
		synctest.Wait()
		if ctx.Err() != context.DeadlineExceeded {
			t.Fatal(ctx.Err())
		}
	})
}
```

## 不要当稳定 API

`encoding/json/v2` 与 `encoding/json/jsontext` 仅 `GOEXPERIMENT=jsonv2`。默认项目不要 import，不要依赖其错误文案。

## vet 与并发写法

- `WaitGroup.Add` 必须发生在 `go` 之前。新代码直接 `wg.Go`（`f` **禁止 panic**）：

```go
var wg sync.WaitGroup
wg.Go(func() { work() })
wg.Wait()
```

不要在子 goroutine 里 `Add(1)`。不要为每个任务手写 `Add`+`go`+`Done`。

- 拼 host:port 用 `net.JoinHostPort(host, strconv.Itoa(port))`，不要 `fmt.Sprintf("%s:%d", host, port)`（IPv6 会坏）。

## 其它会改写法的库

- `os.Root` 补齐 `ReadFile` / `WriteFile` / `MkdirAll` / `RemoveAll` / `Rename` / `Chtimes` / `Chmod` / `Link` / `Symlink` / `Readlink`。已有 `Root` 就用这些，不要退回 `os.*`。
- 模块里要排除目录：`go.mod` 写 `ignore ./node_modules`（仍打进 module zip）。
- 浏览器跨站态变请求：`http.NewCrossOriginProtection().Handler(mux)`。不要为此新造 token CSRF，除非项目已有方案。
