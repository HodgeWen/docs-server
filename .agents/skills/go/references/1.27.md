# Go 1.27

本文件适用于 **`go` 行 1.27.x**。按下面写。1.27.z 是安全与缺陷补丁，不改推荐写法。

## 1.24–1.26 仍该用（细节按需打开旧档）

| 档 | 现在仍用 |
| --- | --- |
| 1.24 | 泛型 type alias；`go.mod` `tool`（不要 `tools.go`）；json `omitzero`；`os.Root`；`for b.Loop()`；`runtime.AddCleanup`；`strings`/`bytes` 的 `Lines`/`SplitSeq`/`FieldsSeq`；std `crypto/mlkem` `hkdf` `pbkdf2` `sha3` |
| 1.25 | 先判 `err` 再解引用；容器感知 `GOMAXPROCS`；`synctest.Test`；`WaitGroup.Go`；`net.JoinHostPort`；`Root.ReadFile`/`WriteFile`/`MkdirAll` |
| 1.26 | `new(expr)`；类型参数自引用约束；`go fix` modernizer；Green Tea GC 默认；`errors.AsType`；`crypto/hpke`；`bytes.Buffer.Peek`；`cryptotest.SetGlobalRandom`；ReverseProxy 用 `Rewrite` |

## 语言：泛型方法

方法可声明自己的类型参数：

```go
type List[T any] struct{ items []T }

func (l List[T]) Map[U any](f func(T) U) List[U] { ... }
```

接口方法**不能**声明类型参数，泛型方法也不能实现接口方法。要挂接口的泛型逻辑仍写包级函数。`math/rand/v2` 的 `Rand` 新增泛型方法 `N`：`r.N(100)` 等价于包级 `rand.N(100)`。

结构体字面量的 key 可以是任意合法字段选择器，嵌套/内嵌字段直接初始化：

```go
p := Player{Name: "bai", Pos.X: 100} // 不必再 Player{Pos: Position{X: 100}}
```

泛型函数赋给匹配函数类型的变量（或做转换）时触发类型推断：`var f func(int) int = identity`，不必再 `identity[int]`。

## 工具

- `go test` 默认跑 `stdversion` vet：用了比 `go` 行更新的 std 符号即报错。要新 API 就升 `go` 行，不要在旧 `go` 行下偷用。
- `go` 行 1.27+ 时 `go mod tidy` 自动合并重复 require 块，只留 direct/indirect 两块。不要手工维护多块。
- `go fix` 新 modernizer：`atomictypes`、`embedlit`、`slicesbackward`、`unsafefuncs`；`fmtappendf` 已删；`waitgroup` 改名 `waitgroupgo`。
- `go doc pkg@version` 查指定版本文档。bzr 支持已删。
- 已移除的 GODEBUG 只能写终值（编译通过、无效果）；写旧值直接构建失败。

## 运行时

goroutine leak profile **转正**：`runtime/pprof` 的 `goroutineleak` 与 `/debug/pprof/goroutineleak` 直接用，`GOEXPERIMENT=goroutineleakprofile` 已删。检测基于 GC 可达性：被全局变量或运行中 goroutine 可达的同步原语上的泄漏查不出，别当全覆盖。

`asynctimerchan` 永久删除：`time` 的 channel 永远同步无缓冲。依赖旧缓冲语义的代码必须改，没有开关。

`go` 行 1.27+ 的 traceback 头行带 goroutine label。label 可能带敏感信息时才 `GODEBUG=tracebacklabels=0`。

小对象（<80B）分配走尺寸特化，最高省 30%，二进制约 +60KB。发现回退报 issue；opt-out `GOEXPERIMENT=nosizespecializedmalloc` 1.28 移除。

编译器简化闭包符号名并可能合并同名字面量：测试不要断言函数字面量的符号名，不要用函数代码指针判等。

## 库

### `encoding/json/v2` 转正

新代码可直接 `import "encoding/json/v2"`，不再需要 `GOEXPERIMENT=jsonv2`；token 级处理用 `encoding/json/jsontext`。v2 默认更严：拒绝非法 UTF-8、拒绝对象内重复名。

v1 `encoding/json` 底层已换 v2 实现：行为保持，但**错误文案可能变**，不要断言错误字符串。v1 API 继续支持，不强制迁移；兼容出问题才 `GOEXPERIMENT=nojsonv2`（未来版本移除），并报 issue。

### std `uuid`

新代码用标准库 `uuid`（RFC 9562），不要再拉第三方 UUID 包：

```go
id := uuid.New()         // 等价 NewV4；要可时间排序用 uuid.NewV7()
id, err := uuid.Parse(s) // 接受连字符/花括号/urn/裸 hex
```

`UUID` 可 `==` 比较；哨兵值 `uuid.Nil()` / `uuid.Max()`。已有第三方依赖的迁移节奏跟项目走。

### `crypto/mldsa`

ML-DSA（FIPS 204）签名用 `crypto/mldsa`，不要手搓。x509 与 TLS 1.3 已支持（`MLDSA44`/`MLDSA65`/`MLDSA87` SignatureScheme）。TLS 另增 `MLKEM1024` 密钥交换，加进 `Config.CurvePreferences` 启用。`tls.Config.Rand` 已弃用：确定性测试用 `cryptotest.SetGlobalRandom`。一批 TLS 相关 GODEBUG（`tls10server`、`tls3des`、`tlsrsakex`、`tlsunsafeekm`、`x509keypairleaf`）永久删除，不要再设。

### 测试

bubble 里「睡够再等安定」用 `synctest.Sleep(d)`，等价 `time.Sleep(d)` + `synctest.Wait()`，比裸 `time.Sleep` 更稳。

HTTP 测试用 `httptest.NewTestServer(t, handler)`：默认内存假网络，不占端口、可进 synctest bubble；handler panic 自动 fail 测试，cleanup 自动注册。不要再 `NewServer` + 手动 `Close`。`server.Client()` 发出的任意 host 请求都到该 server；要真实回环网卡才 `server.Start()`。

### 其它会改写法的库

- 按最后一个分隔符切分用 `strings.CutLast` / `bytes.CutLast`，不要 `LastIndex` 再手切。
- `url.URL.Clone()` / `url.Values.Clone()` 深拷贝，不要逐字段手拷。
- `UnixConn` 读方法遇 EOF 直接返回 `io.EOF`，不再包 `net.OpError`；判 EOF 用 `errors.Is(err, io.EOF)`。
- `big.Int.Divide` 求商余，支持 `Trunc`/`Floor`/`Round`/`Ceil`。
- 哈希类数据结构契约实现 `hash/maphash.Hasher`；comparable 类型直接用 `maphash.ComparableHasher`。
- HTTP/2 server 默认按 RFC 9218 客户端优先级调度；要旧轮询行为设 `Server.DisableClientPriority`。HTTP/1 `Response.Body` Close 时自动排空残余内容以利连接复用。
- `database/sql.ConvertAssign` 与 `driver.RowsColumnScanner` 面向驱动作者，业务代码不碰。
- flate/zip/gzip/zlib/png 的压缩输出字节可能变，测试不要断言压缩后字节流。Unicode 升到 17。

## 实验（默认业务代码不用）

| 开关 | 包/能力 |
| --- | --- |
| `GOEXPERIMENT=simd` | 新增可移植 `simd` 包（向量尺寸无关、全架构）；`simd/archsimd` 修订 amd64 API，新增 arm64 Neon 与 wasm 128 位 |

macOS 最低 13 Ventura。linux/ppc64 改 ELFv2 ABI（内核 3.13+），cgo/PIE/外部链接可用；要纯静态二进制设 `CGO_ENABLED=0`。
