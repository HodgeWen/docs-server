# Go 1.26

本文件适用于 **`go` 行 1.26.x**。按下面写。1.26.z 是安全与缺陷补丁（含 `go fix` 修复），不改推荐写法。

不要用 1.27 才有的：泛型方法、struct 字面量选择器 key、泛型函数赋值推断、`encoding/json/v2` 转正（1.26 仍需 `GOEXPERIMENT=jsonv2`）、std `uuid`、`crypto/mldsa`、`strings`/`bytes` 的 `CutLast`、`synctest.Sleep`、`httptest.NewTestServer`、`url.Clone`、`maphash.Hasher`、goroutine leak profile 转正（1.26 仍要 `GOEXPERIMENT=goroutineleakprofile`）。

1.26 工具链执行 `go mod init` 会写入 `go 1.25.0`。要本档语法时再 `go get go@1.26.0`。

## 1.24 / 1.25 仍该用（细节按需打开旧档）

| 档 | 现在仍用 |
| --- | --- |
| 1.24 | 泛型 type alias；`go.mod` `tool`（不要 `tools.go`）；json `omitzero`；`os.Root`；`for b.Loop()`；`runtime.AddCleanup`；`strings`/`bytes` 的 `Lines`/`SplitSeq`/`FieldsSeq`；std `crypto/mlkem` `hkdf` `pbkdf2` `sha3` |
| 1.25 | 先判 `err` 再解引用；容器感知 `GOMAXPROCS`；`synctest.Test`（不要 `Run`，已删）；`WaitGroup.Go`；`net.JoinHostPort`；`Root.ReadFile`/`WriteFile`/`MkdirAll` |

不要退回 `for range b.N`、`SetFinalizer`、`Sprintf("%s:%d")`、`tools.go`、x/crypto 重复实现。1.26 起 `B.Loop` 不再阻止循环体内联，更不要为了性能退回 `b.N`。

## 语言：`new(expr)`

`new` 可接表达式，得到已初始化指针。json/protobuf 可选字段直接写，禁止先 `var x T; p := &x`。

```go
type Person struct {
	Name string `json:"name"`
	Age  *int   `json:"age"` // 未知则为 nil
}
json.Marshal(Person{Name: name, Age: new(yearsSince(born))})
```

类型参数列表允许自引用约束：

```go
type Adder[A Adder[A]] interface {
	Add(A) A
}
```

## 工具：`go fix`

改写后的 `go fix` 是 idiom modernizer（与 `go vet` 同一套 analysis），**不是**静默格式化。先了解要跑哪些 fixer，再跑，再看 diff。只对 `go` 行（或 `//go:build`）已满足最低版本的文件改写。自有 API 迁移用 `//go:fix inline`。出问题报 issue，不要关了当没看见。`go tool doc` / `cmd/doc` 已删，用 `go doc`。

## 运行时

Green Tea GC **默认开**。不要设 `GOEXPERIMENT=greenteagc`。opt-out 是构建时 `GOEXPERIMENT=nogreenteagc`（1.27 未拿掉，后续版本仍可能移除）；若因行为/性能关掉，要报 issue。不要按旧 GC 停顿模型调参。

## 库

HPKE 用 `crypto/hpke`（含后量子混合 KEM），不要手搓 RFC 9180：

```go
kem, kdf, aead := hpke.MLKEM768X25519(), hpke.HKDFSHA256(), hpke.AES256GCM()
ct, err := hpke.Seal(pk, kdf, aead, info, msg)
pt, err := hpke.Open(sk, kdf, aead, info, ct)
```

`bytes.Buffer.Peek(n)` 看后面 n 字节且不消费；返回短于 n 时带 `io.EOF`。切片只活到下一次读写。

crypto 的 `GenerateKey` / `Sign` / `rand.Prime` 等 **忽略** 传入的 `io.Reader`，始终用安全随机源。测试要可复现：

```go
cryptotest.SetGlobalRandom(t, 42) // 不可与 t.Parallel 同用
```

不要改 `crypto/rand.Reader` 当测试夹具。临时恢复旧行为才用 `GODEBUG=cryptocustomrand=1`。

错误断言优先 `errors.AsType`，不要 `var pe *fs.PathError; errors.As(err, &pe)`：

```go
if pe, ok := errors.AsType[*fs.PathError](err); ok {
	return pe.Path
}
```

新 `httputil.ReverseProxy` 用 `Rewrite`，`Director` 已弃用。

## 实验（默认业务代码不用）

| 开关 | 包/能力 |
| --- | --- |
| `GOEXPERIMENT=simd` | `simd/archsimd`（目前 amd64，API 不稳、非可移植） |
| `GOEXPERIMENT=runtimesecret` | `runtime/secret`（擦机密临时值；linux/amd64+arm64） |
| `GOEXPERIMENT=goroutineleakprofile` | `runtime/pprof` 的 `goroutineleak` 与 `/debug/pprof/goroutineleak` |

不要把这些写进默认生产路径。`encoding/json/v2` 仍实验，规则同 1.25。
